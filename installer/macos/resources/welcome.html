akroasys

This installer will set up akroasys on the selected Mac volume:

  • akroasys.app in /Applications/
  • Model storage in /Library/Application Support/T5ynth/models/

The bundled UCDCAE AI Lab preset bank is seeded into your user library on first launch; use the Update Library button to fetch the latest version from GitHub.

The installer creates the shared T5ynth support folder and installs the akroasys app on that volume.

After installation, launch akroasys and use the Settings panel to download a model.

akroasys is open-source software (GPLv3).
