analogue oscillator / vco / dco / minimoog / juno / prophet: ONE waveform generator with every control the shape needs. `wave` picks between two vco2 generators -- the ramp one and the pulse one -- and `width` is the SAME position on both: the fraction of the period spent in the first phase, symmetric at 0.5.
