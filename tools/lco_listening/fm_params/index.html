the peak FM index: how many sidebands the tone carries -- how bright and rich it is. As it rises the spectrum brightens steeply while the loudness stays constant (a balance stage holds the level), so only the colour moves, never the volume.…
Verdrahtung abgeleitet. Der Eintrag hat keine Zeile, die index beim Namen nennt — aber unter anchor_code steht pro Anker ein ganzer Körper, und alle unterscheiden sich vom ausgelieferten Code in genau einer Zahl in genau einer Zeile (Zeile 6). Diese Seite spielt an jedem Anker den Körper des Eintrags Zeichen für Zeichen; kombiniert wird über die Gerade durch diese Punkte (14.9315·index +1.05861), die den ausgelieferten Code an seiner eigenen Vorgabe wiedertrifft — einer Vorgabe, die nicht unter den gefitteten Punkten steckt, sonst prüfte sie nichts.

Deklariert, aber kein Regler: eine feste Zahl im Code

ring, detune trägt im Eintrag Bereich, Vorgabe und Ankerwörter, aber der code nennt die Achse nirgends und die Ankerkörper leiten keine Stelle her. Die GRÖSSE steckt durchaus im Code — fms Schwebung etwa als das feste + 1.2 Hz, um das die zweite Stimme höher steht — nur eben als eine Zahl an einem Punkt, und welche Zahl der Regler bewegen soll und auf welcher Kurve, sagt der Eintrag nicht. Das zu entscheiden hieße, die Verdrahtung zu ERFINDEN: das Instrument schreiben statt es vorzuspielen. Die Achse steht deshalb hier und nicht oben, und was du oben hörst, steht auf ihrer Vorgabe.
