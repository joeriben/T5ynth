# Semantic-axis grounding research

Runnable scripts behind the SA3 bundled-pole semantic axes (commit `1d12ff5e`).
**Read `docs/SEMANTIC_AXES_GROUNDING.md` first** — it is the method; this is the
implementation. Findings summary lives in memory `project_aesthetic_axes_study`.

Everything talks to the model over the **IPC subprocess** (`PipeClient` →
`.venv/bin/python backend/pipe_inference.py`), never a direct import — the same
path the plugin uses. Paths are derived from `__file__`, so the scripts run
in-place from the repo. Audio/output trees (`*_out/`, `*.wav`) are `.gitignore`d
and regenerated by re-running the scripts.

## Scripts (run order)

| script | step (see grounding doc) |
|---|---|
| `audition_axes_mac.py` | shared harness: `PipeClient`, `write_wav`, model/dur/steps/cfg constants, numpy metrics. Imported by the rest. Its own `main()` is the *older* PCA audition (needs `pca_components_sa3.pt`, not included) — kept for the harness, not that entry point. |
| `bundle_poles.py` | 1–3 · build synonym-**bundled** poles, check seed-stability, separate them on rhythm-competent features (pulse / crest, not onset count). |
| `bundle_inject.py`, `bundle_inject_rhythm.py` | 4 · inject the bundled direction (sustained/transient; rhythm) onto sustained bases. |
| `bundle_mask_test.py` | 5 · masked vs unmasked survival — decides whether an axis ships plain or needs the `unmask_manipulation` path. |
| `pin_transient_and_unmask.py` | transient dose-pin + proof the shipped single-word axes are inert masked *and* unmasked. |
| `gen_masked_and_rebuild.py` | 6 · renders the masked comparisons and builds `listening_final.html`. |
| `listening_final.html` | example audition page. WAV cells reference the (gitignored) `*_out/` trees — regenerate them by running the scripts above. |

## Run

```bash
.venv/bin/python tools/sem_axes_research/bundle_poles.py       # step 1–3
.venv/bin/python tools/sem_axes_research/bundle_mask_test.py   # step 5
.venv/bin/python tools/sem_axes_research/gen_masked_and_rebuild.py  # step 6 -> listening_final.html
```

SA3 params are baked in (8 steps, cfg 1.0, `stable-audio-3-medium`); a fixed seed
isolates the axis from seed scatter. For a **new model**, follow the checklist at
the end of `docs/SEMANTIC_AXES_GROUNDING.md`.
